# P2 Profile Git Report

Date: 2026-08-06

## Scope

P2 now treats the existing MO2 `profiles/` git repo as the source of truth. It does not
reinitialize that repo, `.gitattributes`, or `.gitignore`; those were already established
in the live profile repo baseline `ae3cf71`.

## Design Correction

The original P2.3 byte-identical rollback criterion is invalid for this setup. Running
Skyrim / MO2 can legitimately rewrite profile files:

- `loadorder.txt` may regain these Creation Club entries:
  - `ccbgssse068-bloodfall.esl`
  - `ccbgssse069-contest.esl`
  - `ccvsvsse004-beafarmer.esl`
- `plugins.txt` may have its header / formatting regenerated by MO2.

The gate is now semantic equivalence:

- enabled mod set
- mod order
- active plugin set
- plugin relative order, excluding the three known engine-written CC entries
- `archives.txt` entries

## New Interfaces

- `mo2ctl profile-status`
  - Reports active profile, profile repo branch/head/dirty state, manifest mods, and
    whether MO2/game locks make the profile writable.

- `mo2ctl profile-semantics [--ref HEAD] [--show]`
  - Compares the current profile against a git ref by semantic state rather than bytes.

- `mo2ctl profile-absorb-churn [-m MESSAGE]`
  - Commits known MO2/engine churn when semantic state still matches `HEAD`.
  - Refuses if dirty paths or semantic changes fall outside the whitelist.

- `mo2ctl select-profile <profile>`
  - Updates `ModOrganizer.ini`'s `selected_profile=@ByteArray(...)` by byte-level line
    replacement.
  - Preserves the original line ending and asserts the key appears exactly once.

- `mo2ctl try-begin <name> [--branch try/name]`
  - Requires MO2/game to be closed.
  - Absorbs known churn first, then creates a clean `try/<name>` branch.

- `mo2ctl try-fail [--uninstall MOD]`
  - Removes mods added to `manifest.json` since `main`, restores profile files from git,
    checks out `main`, and deletes the try branch.

- `mo2ctl try-pass [-m MESSAGE] [--delete-branch]`
  - Commits the current try branch if needed, then fast-forwards `main`.

## Manifest

`mo2ctl install` updates `profiles/manifest.json` unless `--no-manifest` is passed. Each
entry records:

- mod name, profile, enabled state, priority, version
- source path and optional `--source-url`
- source kind and archive sha256
- `archive_library` status from `mongodb://127.0.0.1:27018/skyrim.archives` when a local
  `mongosh` / `mongo` client can answer quickly
- plugin and archive file lists
- replayable `mo2ctl-fomod-choices-v1` data when present

`mo2ctl uninstall` removes the matching manifest entry unless `--keep-manifest` is used.
